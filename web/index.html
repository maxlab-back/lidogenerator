Автопоиск

      
Сохранённые поиски запускаются сами по расписанию, пока работает сервер. Новые компании попадают в «Базу», сводка — в Telegram.

    

    
 

  

  

  
Автопоисков пока нет. Настрой поиск на вкладке «Поиск» и нажми «⏰ Сохранить как автопоиск».






  

    

      
Ключи API

      
Вставь ключ, нажми «Сохранить и проверить» — источник заработает сразу, перезапускать сервер не нужно.
        Ключи лежат на сервере в файле .env, в браузер целиком не отдаются.
